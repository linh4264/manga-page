# 🚀 DriveManga - Google Drive Manga Reader

Ứng dụng web đọc truyện PDF & Google Drive hiện đại.

---

## ⚡ Hướng dẫn chạy ứng dụng trên cổng 3000 (Port 3000)

### Cách 1: Sử dụng NPM (Khuyên dùng)
```bash
npm run dev
# hoặc
npm start
```

### Cách 2: Sử dụng NPX
```bash
npx serve -p 3000
```

### Cách 3: Sử dụng Python
```bash
python -m http.server 3000
```

Sau khi chạy một trong các lệnh trên, truy cập ứng dụng tại:
👉 **[http://localhost:3000](http://localhost:3000)**
